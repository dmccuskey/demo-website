The Virtual Infrastructure Simulator is a small system that keeps running: virtual users send commands, virtual servers work through them, and the servers are scaled to keep up.

It does not model real infrastructure. It demonstrates LiveSystem, a lightweight framework for applications whose state and behavior remain alive over time.

The page only displays what happens on the server, and its controls send commands. Everyone who has the page open sees the same system, and it starts over each night.
